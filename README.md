## Исправления доступности

- Для пропуска меню добавлена ссылка на `main` с `id="main-content"` и `tabindex="-1"`.
- Исправлено переопределение стилей фокуса для ссылок, кнопок и полей; добавлен контур для кнопки «Наверх».
- Текущие страницы в меню обозначены атрибутом `aria-current="page"`.
- Уточнён `alt` фотографии на странице тура.
- Подсказки телефона связаны с полями через `aria-describedby`.
- Ошибки формы выводятся текстом и связываются с полями через `aria-describedby`; используется `aria-invalid`.
- При отправке некорректной формы фокус переводится на первое ошибочное поле. После исправления сообщения удаляются.
- Ссылка со страницы контактов направлена на форму заявки.

## Самостоятельные доработки

- **Мобильное меню:** до 768px навигация раскрывается кнопкой. Поддерживаются клавиатура, Esc, возврат фокуса и `aria-expanded`. На широком экране меню постоянно видно; без JavaScript ссылки доступны.
- **Фильтры каталога:** до 1024px блок раскрывается через `details` и `summary`. Значения полей сохраняются при закрытии. Esc закрывает фильтры и возвращает фокус; на компьютере блок всегда раскрыт. Доработка меняет представление фильтров, а не добавляет поиск туров.
- **Характеристики тура:** до 768px строки таблицы отображаются карточками «параметр — значение». Сохраняется одна таблица без дублирования данных; заголовки строк связаны через `scope`. На широком экране используется обычное табличное представление. Исправлена разметка контейнера таблицы.
- **WebP:** подготовлены версии фотографии тура шириной 480, 960 и 2400px. Через `picture` браузер получает WebP, при отсутствии поддержки — JPEG. Размер файлов уменьшен примерно на 37–55% относительно соответствующих JPEG.

Проверка доработок: пять страниц открыты в браузере на ширинах 360, 430, 768, 1024 и 1440px; горизонтального переполнения нет. Проверены закрытие меню через Esc и возврат фокуса, управление фильтрами с клавиатуры, сохранение значений, переключение ширины, загрузка WebP и работа навигации и фильтров без JavaScript. Ошибок JavaScript при проверке не обнаружено.

После этих изменений необходимо повторить Lighthouse и обновить скриншоты в `lighthouse/`. Прежние оценки выше относятся к предыдущей версии.

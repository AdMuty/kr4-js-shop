# Контрольная работа №4

Тема: «JavaScript: интерактивность, DOM, события, формы и валидация».

## Основа проекта

TURIST bezgranits — учебный сайт туристического агентства. Проект `kr4-js-shop` создан на основе собственной адаптивной HTML/CSS-версии из КР №3. Сохранены страницы, адаптивные стили, мобильное меню, модальное окно и обработка формы.

## Практическая работа №15

Выполнено:

- подготовлен отдельный проект `kr4-js-shop` на основе КР №3;
- создан `js/data.js` с объектом одного тура;
- дополнен существующий `js/main.js`;
- скрипты подключены через `defer`: сначала `data.js`, затем `main.js`;
- использованы `const`, строки, числа, логические значения и объект;
- применены арифметические операции, сравнения и логический оператор `&&`;
- реализованы `formatPrice`, `calculateDiscount`, `calculateFinalPrice`, `getProductStatus`, `createProductSummary`;
- объект и результаты функций выведены через `console.log` и `console.table`;
- на главной странице добавлен учебный блок с выводом через `textContent`;
- перед обновлением содержимого проверяется наличие элементов страницы.

## Файлы JavaScript

- `js/data.js` — объект `product`: идентификатор, название, категория, цена, скидка, рейтинг, доступность.
- `js/main.js` — функции практики №15, вывод результатов и сохранённая логика интерфейса из КР №3.

При цене 200000 рублей и скидке 10% размер скидки составляет 20000 рублей, итоговая цена — 180000 рублей. Функции возвращают результат через `return`; форматирование цены выполняется после расчётов.

## Принцип безопасного вывода данных

Текстовые данные выводятся через `textContent`: строка не интерпретируется как HTML. В учебном блоке строка `<strong>Текст пользователя</strong>` отображается вместе с тегами. Использование `innerHTML` интерпретировало бы эту строку как разметку, поэтому для пользовательского текста применяется `textContent`. Активного небезопасного примера в проекте нет.

## Запуск и проверка

1. Открыть `index.html` в браузере.
2. Открыть инструменты разработчика → Console.
3. Проверить сообщение о подключении, таблицу свойств тура и результаты пяти функций.
4. Внизу главной страницы проверить блок «Проверка JavaScript» и пример безопасного вывода.
5. Открыть остальные страницы и убедиться в отсутствии ошибок JavaScript.

Для этой практики сервер и установка зависимостей не требуются. При необходимости локального запуска через HTTP из папки проекта:

```powershell
npx.cmd --yes http-server . -a 127.0.0.1 -p 8001 -c-1
```

Затем открыть `http://127.0.0.1:8001/index.html`.
